# Transient Branch Selection and Delivered Stabilizer Amplitude in a Bistable Mean-Field Model

Code, data, and manuscript sources for a matched-seed simulation study of collapse
probability in a bistable mean-field system.

## The model

A Curie–Weiss stochastic differential equation for an order parameter *m*(*t*) ∈ (−1, 1)
under coupling *J*, coupled to a slow variable *W*(*t*) that feeds a bounded protective
field *h*(*W*) = 2·(*W*/500):

```
dm/dt = −m + tanh((J·m + h(W))/T) + ξ·√(1 − m²)·η(t)
dW/dt = μ·employment(m) − consumption(W)
```

with employment(*m*) = (1 + *m*)/2, consumption(*W*) = 30 + 10·(*W*/500), *T* = 2,
ξ = 0.5, and *W* floored at 0. The paper measures two matched-seed observables —
wrong-branch selection and wealth collapse — and characterises the early (transient
branch-selection) and late (noise-activated escape) collapse channels; reports a
pre-registered magnitude-matched control showing that matching a stabilizer's
full-trajectory delivered mean does *not* reproduce its collapse outcome; and measures
the superlinear growth in coupling of the wealth-coupling coefficient required to hold
collapse probability fixed.

## Reproducing the results

All simulation results are generated from random seeds with no external data.
`REPRODUCIBILITY.md` maps every headline number and figure to the script that produces its data (and, for Figures 2 and 5 and Supplementary Figures S1–S4, the script that renders it).
Quick start (each line runs the simulation behind a figure, not the figure rendering):

```bash
python simulation/scripts/run_sweep.py            # data for Figure 1 (9,000-run sweep)
python simulation/scripts/active_stabilizer.py    # data for Figure 2 (stabilizer contrast)
python simulation/scripts/level2_with_beliefs.py  # data for Figure 4 (ablation cascade, L2)
python simulation/scripts/level3_with_credit.py   # data for Figure 4 (ablation cascade, L3)
python simulation/scripts/reduction_validity.py   # data for Figure 5 (reduction validity)
python simulation/scripts/ramp_speed_sweep.py     # data for Figure 3 (ramp experiments)
```

The released figure-rendering scripts are `fig1_static_asymmetry.py` (Figure 1), `active_stabilizer_figures.py` (Figure 2), `fig5_reduction_validity.py` (Figure 5), `level0_pure_cw.py` (Supplementary Figure S1), `sensitivity_figure.py` (S2), `scaling_control.py` (S3), and `alternative_class_figure.py` (S4). Figures 3 and 4 are two-row composites of panels regenerated by released scripts (`ramp_speed_sweep.py`, `ablation_compare.py`).

The manuscript's reference list renders in the built PDFs from `manuscript/references.bib` (via `manuscript/arxiv/build_tex.py`).

Requires Python 3.13 with numpy, scipy, matplotlib, pandas, and networkx, plus
scikit-learn and diptest for the scope-probe classifier
(install with `pip install -r requirements.txt`); rebuilding the PDFs additionally
requires `pandoc` and a LaTeX distribution (xelatex). Seeds are set
deterministically in each script; see `REPRODUCIBILITY.md` for the seed convention.

## Rebuilding the manuscript PDFs

```bash
cd manuscript/arxiv
python build_tex.py            # regenerates main.tex, paper_only.tex, supplementary.tex
xelatex paper_only.tex && bibtex paper_only && xelatex paper_only.tex && xelatex paper_only.tex
```
