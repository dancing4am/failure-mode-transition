# Reproducibility

**Manuscript:** *"Transient Branch Selection and Delivered Stabilizer Amplitude in a Bistable Mean-Field Model: Matched-Seed Measurements of Collapse Probability"*.

**Author:** Chowon Jung.

This file is the public-facing reproducibility manifest for the computational results in the manuscript and Supplementary Information. Every reported figure and headline number is listed with the script that produced it. All simulation results are generated from random seeds and require no external data.

## Repository layout

```
.
├── manuscript/
│   ├── paper.md
│   ├── supplementary_information.md
│   ├── references.bib
│   └── arxiv/            (LaTeX build + built PDFs + figures)
├── simulation/
│   ├── scripts/         (Python: model + sweeps + controls + figures)
│   ├── results/         (CSV / npz / PNG outputs behind every reported simulation number)
│   └── prereg/          (frozen pre-registrations: alpha-fit, magnitude-matched, late-channel)
├── scope_probes/        (out-of-scope substrate checks: SIR, neural network, DOPO; power grid is a literature-level classification only, no code)
├── empirical/
│   └── PHASE2_PREREGISTRATION.md   (frozen pre-registration of the shape test cited in the Discussion)
├── README.md
├── REPRODUCIBILITY.md   (this file)
└── LICENSE
```

`simulation/scripts/*.py` need no external data — they generate their own outputs from random seeds.

## Pre-registered analysis design

Four frozen pre-registrations are archived as dated evidence. Where a line was editorially redacted for public release, the redaction is recorded in an "Editorial amendment" block inside the document itself, with the git blob hash of the unedited original: all four (`PREREG_alpha_fit_2026-05-30.md`, `PREREG_magnitude_matched_informative_2026-08-21.md`, `PHASE2_PREREGISTRATION.md`, and `PRESPEC_late_channel_mechanism_2026-08-22.md`) carry such a block. No redaction touches a design, grid, threshold, or decision-rule element:

- `simulation/prereg/PREREG_alpha_fit_2026-05-30.md` — the collapse-observable α-fit protocol, fixed before the measurement.
- `simulation/prereg/PREREG_magnitude_matched_informative_2026-08-21.md` — the pre-specified analysis plan for the informative magnitude-matched (stress-variant) control.
- `simulation/prereg/PRESPEC_late_channel_mechanism_2026-08-22.md` — the pre-specification of the late-channel mechanism tests (SI §S9), committed before the results existed.
- `empirical/PHASE2_PREREGISTRATION.md` — the pre-registered shape-discrimination test whose out-of-sample result (ΔOOS = +0.033 nats) the Discussion reports. The test was run on an observational panel that is not part of this submission; the pre-registration is retained so the reported negative result is documented against its frozen protocol. `empirical/` contains this frozen document only: the artifacts it references (`close_prices.csv`, `tail_risk_frequency.py`, `phase2_discriminating_test.py`, `convexity_test.py`, `ai_coupling_overlay/`) were part of a prior version and are not in this deposit, and its "§S10" refers to a prior SI numbering.

The 9,000-run sweep grid (J ∈ {0.5, …, 5.0}, μ ∈ {20, …, 100}, 100 seeds) and dt = 0.05 integration step are pre-specified in the script defaults; all reported simulation results derive from the same configuration.

### Determinism and random seeds

Every stochastic simulation script derives its seeds deterministically from a fixed base constant and a grid-index formula (e.g. `seed = 0xC0DE + j_idx * 1_000_003 + m_idx * 1009` for the minimal-model sweep), so reruns are bit-exact. Four scripts — `simulation/scripts/sensitivity_sweep.py`, `alternative_class_sweep.py`, `dynamic_j.py`, and `oat_sensitivity.py` — additionally fold Python's `hash()` of a variant/schedule label into the seed; since string hashing is randomized per process, each of these scripts begins with a reproducibility guard that re-executes itself with `PYTHONHASHSEED=0`. The archived results for those four scripts predate the guard, so regenerated runs are statistically consistent with, but not necessarily bit-identical to, the archived CSVs; reported band- and grid-level conclusions from them are robust to regeneration, but individual 100-seed cells and small-count type shares shift within binomial sampling error (e.g. the sudden-onset rigidity share at margins with ~10 collapsed seeds, and the §S5.2 envelope edges); the archived CSVs are authoritative for every reported number. One further platform caveat: the arcsin-Lamperti (boundary-preserving) integrator legs of `boundary_integrity.py`, `late_channel_check.py`, `late_channel_dt_convergence.py`, and `late_channel_mechanism.py` regenerate bit-exactly on the archiving platform — Windows 11; the archived results were generated under the documented Python 3.13 environment above, and bit-exact regeneration has been verified under both CPython 3.13.3 (numpy 2.3.3, scipy 1.16.2) and CPython 3.14.3 (numpy 2.4.6, scipy 1.17.1) — but only statistically on Linux, where libm differences in the transcendental calls shift individual trajectories (e.g. a regenerated SI §S9 barrier-scaling slope of −11.03 versus the archived −10.55, still inside the pre-registered failure edge of −11.2, so the §S9 conclusion is unchanged); the clipped-EM legs of the same scripts regenerate bit-exactly on both platforms, and the archived CSVs are authoritative.
