## 1. Purpose

Provide an **informative** magnitude-matched constant-field control for
**headline claim 3**: *within static sweeps (J held constant per run), the
delivered field amplitude — not the functional form of the stabilizer response —
decides the outcome.* This prereg targets the **stress variant** of the active
stabilizer,

```
h_stress(W, m, J) = base + alpha * max(0, -m) * J,   base = b * (W / 500)
```

with the standard field scale `b = 2` (i.e. `base = 2*(W/500)`) unless the
search procedure below forces a reduction.

### Why a new control is needed

The pre-existing control
(`simulation/results/magnitude_matched/collapse_comparison.csv`, generated by
`magnitude_matched_control.py` at `alpha = 2.0`, `mu = 100`) compares two arms
that are **both all-zero**: at every J tested, `P(stress-form collapse) = 0.000`
and `P(constant = full-trajectory mean) = 0.000`. Two all-zero arms trivially
"agree", so that control **cannot discriminate** the two competing hypotheses:

- **H_magnitude (claim 3):** delivered magnitude decides; a pure constant field
  matched to the stress form's delivered mean reproduces the stress outcome.
- **H_form:** the response *form* (state-dependent, feedback-coupled) decides;
  a magnitude-matched constant does *not* reproduce it.

To discriminate, we must first find an **informative operating point** where the
stress form's collapse probability is strictly inside the open band
`0.10 < P(collapse) < 0.50`, and then run the matched constant control there.

`dt = 0.05`, `N_STEPS = 20000` (T_phys = 1000), `T (temperature) = 2.0`,

## 3. Search procedure for the informative operating point (declared in advance)

The stress term is a **stabilizer**: a larger field drives `m` toward +1, raises
employment and wealth, and *suppresses* collapse. Therefore **reducing** the
stress response coefficient `alpha` (and, if necessary, the base field scale `b`)
*raises* `P(stress-form collapse)` from the fully-stabilized `P = 0` seen at
`alpha = 2.0`.

**Search cell:** the headline cell `J = 5, mu = 100`, `n = 2000` seeds.

**Primary scan (alpha):** with `b = 2` fixed, scan
```
alpha in {0.05, 0.10, 0.15, 0.20, 0.30, 0.50}   (ascending)
```
Because `P(collapse)` is monotonically non-increasing in `alpha` (weaker
stabilizer -> more collapse), the smaller alphas give the higher `P`. We select
the **smallest-index (smallest) alpha whose `P(stress collapse)` at the headline
cell falls strictly inside `(0.10, 0.50)`**, i.e. the strongest-stabilizer /
lowest-P operating point that is still informative. (Equivalently: among all
grid alphas with `P` in band, take the largest alpha — see NOTE. The
instruction as written is "smallest-index alpha giving P in band"; we follow it
literally and additionally report the full scan so the choice is auditable.)

> NOTE on ordering: since P decreases with alpha, the in-band alphas form a
> contiguous run. "Smallest-index alpha giving P in band" = the smallest alpha
> that is still `<= 0.50` in P (highest P still in band). We commit to that rule
> as written: **pick the smallest alpha in the grid whose headline-cell P is
> strictly inside (0.10, 0.50).**

**Fallback (base scale), only if no grid alpha lands in band:** if *every* alpha
in the grid gives `P <= 0.10` at the headline cell (base field alone suppresses
collapse) — or, symmetrically, every alpha gives `P >= 0.50` — then lower the
base field scale and rescan the full alpha grid:
```
b in {1.5, 1.0, 0.5, 0.25}   (descending; lower b => weaker field => higher P)
```
Select the **smallest-index `(b, alpha)` combination** (first by descending-b
index, then by ascending-alpha index) whose headline-cell `P(stress collapse)`
is strictly inside `(0.10, 0.50)`. If no `(b, alpha)` on the declared grids lands
in band, the search is declared **failed** and the control is reported as
"no informative operating point found" (no verdict on claim 3).

The chosen `(b, alpha)` — call it `(b*, alpha*)` — defines the operating point
used for the matched control.

## 4. Matched-seed control design (declared in advance)

At the chosen `(b*, alpha*)`, for each test cell (Section 6):

1. **Stress arm.** Run `h_stress` and record, over the WHOLE run, the
   **full-trajectory delivered mean field**, defined exactly as
   ```
   h_bar_full = ( 1 / (N_STEPS * n_seeds) ) * sum_{t=0}^{N_STEPS-1} sum_{s=0}^{n_seeds-1} h_{t,s}
   ```
   i.e. the time-average of `h` over all 20000 steps, averaged across all `n`
   runs (this is the `full_mean_h` quantity computed by the existing engine).
2. **Constant arm.** Run a **pure constant field** `h_const = h_bar_full`: no
   wealth feedback in the field, no stress term — the field is the single scalar
   `h_bar_full` at every step.
3. **Matched seeds.** Both arms use the **same base seed per cell** and the same
   RNG call pattern (one `standard_normal(n_seeds)` draw per step), so the noise
   increments `dW` are **identical draw-for-draw** between the two arms. The
   comparison is therefore **paired per seed**.
4. `n = 2000` seeds per arm per cell.

Seeds: `seed(cell) = 0xE1_1B01 + j_idx * 1_000_003` (distinct from the existing
`0xE1_0001` control so results are independently regenerable).

---

## 5. Decision rule (declared in advance)

Let `diff = P(stress) - P(const)` be the paired difference at a cell, with a
95% **paired bootstrap CI** (10,000 resamples over the 2000 matched seeds).

- **REPRODUCED** (consistent with claim 3, stress variant): the 95% CI of `diff`
  **contains 0** AND `|diff| <= 0.03`.
- **REFUTED** (falsifies claim 3 for the stress variant): the 95% CI of `diff`
  **excludes 0** AND `|diff| > 0.05`.
- **INCONCLUSIVE:** any outcome that is neither of the above (e.g. CI excludes 0
  but `|diff| <= 0.05`; or CI contains 0 but `|diff| > 0.03`).

Both numeric thresholds are fixed here in advance: reproduce band `|diff| <= 0.03`;
refute band `|diff| > 0.05`; the gap `(0.03, 0.05]` and the CI/point-estimate
mismatches are the inconclusive zone.

**Overall verdict:** the headline cell `J = 5, mu = 100` is decisive for claim 3.
The additional cells corroborate. The overall verdict is REPRODUCED only if the
headline cell is REPRODUCED and no additional cell is REFUTED; it is REFUTED if
the headline cell is REFUTED; otherwise INCONCLUSIVE.

## 8. What each outcome would mean

- If the constant field **reproduces** the stress form in this *informative*
  regime, claim 3 is supported for the stress variant: magnitude, not form,
  decides.
- If the constant field **does not reproduce** it (CI excludes 0, `|diff| > 0.05`),
  claim 3 is **falsified for the stress variant** — the state-dependent,
  feedback-coupled *form* carries outcome-relevant information beyond its
  delivered mean. This will be reported plainly, whichever way it comes out.
